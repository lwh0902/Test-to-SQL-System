# 统一授权与安全边界设计

## 目标

在不移除个人数据库分析主流程的前提下，建立集中、可复用的授权和只读数据访问边界，修复 P0 与 P1 清单中的认证、对象级授权、SQL/MCP、网络连接、数据外发、错误处理和滥用防护问题。

## 范围

本设计覆盖 VUL-001、VUL-002、VUL-003、VUL-004、VUL-005、VUL-006、VUL-007、VUL-008、VUL-009、VUL-010、VUL-011、VUL-014、VUL-015、VUL-016。浏览器 token 存储、CORS 与长期可观测性改造不在本批实现范围内，仍保留在漏洞台账中。

## 架构

### 1. 授权边界

新增一个集中授权服务，所有面向用户的资源操作都通过明确的资源—主体校验：

- `require_space_access(space_id, user_id)`：系统空间允许认证用户访问；个人空间仅创建者访问；不存在或无权均返回 404。
- `require_session_access(session_id, user_id, space_id)`：验证会话属于当前用户且属于当前空间。
- `require_trace_access(trace_id, user_id)`：验证 Trace 属于当前用户。

API 层在调用 Agent、schema、profile、持久化前执行校验；服务层使用带 `user_id` 的查询作为纵深防御。这样不会因新增接口而重新复制或遗漏所有权逻辑。

### 2. 身份与配置

公开注册只接受手机号、密码与显示名，服务端永久将角色设为 `tester`。应用启动时验证 JWT 密钥：空值、已知默认值或不足 32 字符均拒绝启动。数据库连接加密密钥也在启动时验证 base64 格式及解码后是否为 32 字节。

### 3. 只读 SQL 策略

新增统一的只读 SQL 策略对象，供指标查询、自由查询与 MCP 共同使用：

- 仅单条 `SELECT`，拒绝 AST 任意位置的 DML/DDL；
- 只允许当前空间发现 schema 中的表，拒绝 catalog/database 限定名；
- 按 schema 的列集合检查列访问，拒绝精确及分类为敏感的数据列；
- 不允许 `SELECT *`，没有 LIMIT 时追加限制，超过上限时拒绝；
- 采用函数允许列表/副作用函数拒绝列表，禁止锁、睡眠和文件/变量类函数；
- 数据库连接使用只读事务与 MySQL 语句超时；预检错误默认拒绝而非静默放行。

MCP 不再导出原始 `execute_query` 工具。若内部仍需要查询，只能调用同一个策略验证后的执行函数。

### 4. 外部数据库与数据外发

删除未保存连接的测试与 schema 发现 API，避免服务端接受任意 host/port。已保存连接的测试保留，但仅针对当前用户的连接、受输入限制与限流。

默认不采样真实业务行，也不将真实样例拼接进 LLM prompt。LLM 仅收到表名、列名、类型、注释及明确许可的非敏感元数据。profile 不再把 `sample_data` 写回数据库。

### 5. 错误、审计与限流

新增请求关联 ID 与结构化安全审计事件；客户端只得到稳定错误码和通用中文提示，底层异常仅进入服务端日志。对 chat、profile、连接测试按用户与 IP 配置限流，记录授权拒绝、SQL 拒绝、连接测试和敏感配置失败事件。

## 数据流

```text
认证用户
  → API 资源校验（space/session/trace）
  → Agent 或资源服务
  → 统一只读 SQL 策略
  → 只读数据库连接（超时/结果限制）
  → 脱敏响应 + request_id
  → 审计事件（授权、策略、错误、限流）
```

## 错误策略

- 未认证为 401；不存在或不属于当前用户的资源统一返回 404。
- SQL、schema、预检或安全配置异常一律 fail-closed，不执行查询。
- 外部数据库异常不返回驱动/网络/凭据信息；记录 request ID。
- 在开发启动时若必要密钥不合格，拒绝启动而非降级运行。

## 测试与验收

每个漏洞修复均按 Red → Green → 回归执行：先新增一个会失败的安全测试，确认失败原因正确，再写最小实现并复跑单测和全量后端测试。必须覆盖双用户空间、会话、Trace 隔离；注册角色；默认密钥拒启；自由 SQL/MCP 拒绝路径；无样例外发；连接端点移除；通用错误；限流；超时/上限策略。每项最终在 `项目漏洞.md` 写入方法、可观测性与实际命令输出。

## 明确决策

- 删除 `/api/connections/test-direct` 与 `/api/connections/discover-schema`，不保留兼容开关。
- 保留个人数据库分析，但不保留未经验证的原始 SQL 执行能力。
- 权限错误返回 404，以降低资源 ID 枚举价值。
- 本批默认关闭真实样例给 LLM，而非尝试扩展字段名黑名单。
